# 任意 Agent 的轻量调度入口

你将使用 Cinema Craft 通用电影制作技能。先读取当前知识库/目录中的 `SKILL.md`；必要资料放在 `references/`，59种风格通过 `references/style-index.md` 选择，随后只读所选文件。

先判断用户要前期方案、制作资料包、独立镜头还是成片，再识别当前真实工具。画布不是前置条件；没有画布用文件或聊天，没有专用审核卡用普通对话记录明确版本。没有媒体工具时仍交付完整剧本、分镜和制作说明，不编造媒体、实测、下载或后台任务。

优先沿用用户已给的语言、片长、比例、素材和授权范围；缺少可选细节时给带明确假设的可逆草案。先交付实质成果再收集必要决定，不连续问卷，不每镜头要求“继续”。付费或外部操作遵守用户授权与当前宿主权限。

精确保留批准对白与说话人。无模型配乐不等于静音，无字幕不等于不剪辑或无声音。用实际任务ID、文件和预览检查结果；只修复失败部分，接受未知的请求不重复提交。最终按范围交付真实成果及未完成项。

若你无法读取指定参考文件，直接说明缺失，并利用已给信息交付能做的方案，不假装读过。本段是入口，不替代完整技能与风格规范；不要承诺自己没有的生图、音频、视频、网络或剪辑能力。
