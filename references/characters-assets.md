# 角色、场景、道具与声音资产

## 由完整剧本自动提取

读取所有场景、出入场、动作与台词归属，建立去重角色表。包括可识别的无名角色、静默角色、短暂出场角色及真正具有角色身份的动物/非人主体。合并别名但区分同职务的不同人。纯旁白无需肖像；始终不露脸的画外声音无需虚构人物图；场所、车辆和普通物件归入场景/道具，不因视觉重要就成为人物。

为角色、场景状态和道具记录稳定 ID、剧本证据、外观/服装/状态、所需镜头、实际素材与版本。不要求用户重新提供已有剧本可直接推导的名单。已有适配素材优先复用，非必要远景群众不逐一生图。

## 角色参考图的三模块提示词

用户没有其他要求时，推荐一张16:9身份参考图：纯白背景 #FFFFFF，左侧完整清晰的正面头肩面部特写，右侧同一角色的正面、严格左侧面、背面三个全身视图。三全身人物同尺度同基线，头脚完整，间距清楚；面部特写用独立尺度。不加图内文字、编号、边框、水印或场景；这些放在外部标签。

1. **版式与跨视图约束**：左侧头顶至下颌及五官完整；右侧依次正面、90度左侧面、背面，侧面鼻尖朝图的左边；各视图身份、服装、材料、配色、发型及比例一致，姿态自然。非人角色按真实设定的解剖结构适配，不额外生成人类手指。该版式是推荐的身份资产方案，不是所有宿主必须支持的 API 布局。
2. **风格、材料与参考照明**：应用已选风格的实际媒介。参考光中性、曝光适中、局部色稳定，阴影高光和材质清楚，不用灰白雾遮住身份；不能为了中性展示抹掉水墨、像素、黏土等风格。影片的戏剧照明另写在镜头中。
3. **具体角色设计**：根据剧本选定年龄呈现、体态、脸型、眉眼鼻唇、皮肤/表面、妆容、发型、服装剪裁/颜色/面料、鞋和标志配饰。设计需具体且互相兼容，不把所有角色自动美化。地域/国籍通过时代、服饰、生活环境与个体设计体现，不把国籍当成固定脸型或肤色。

图像模型、质量、分辨率与其他开关由用户偏好、实际工具能力和预算决定。原 Lumina 的固定模型/medium/image-area-OFF 参数不再是通用要求；保留设计目标，绑定真正支持的字段并检查保存结果。

## 家族关系与外观变体

仅从剧本/明确要求提取亲缘关系，记录方向和证据，不从照片推断血缘。配偶、姻亲、收养关系不默认共享脸部。需要家族相似时先完成一个适用来源角色的真实参考图，按项目审核要求确认该锚点后再生成有依赖的亲属；无关资产可继续。不要等待“全家都完成”才批准唯一必要锚点而造成死锁。

使用少数稳定的脸部轮廓、眉眼或鼻部特征，同时保留目标角色的年龄、体态、发型、服装与独特身份；不是给同一张脸换衣服或套老化滤镜。保存来源角色/图像/版本及相似线索。外观继承不授予声音克隆许可。源图改变只影响真正依赖的成员和镜头。

服装、受伤、湿润、老化、开合等状态均以角色/物件原身份关联，避免每个镜头出现“新角色”。

## 检查与实际引用

对每个具体图像版本检查一次完整身份、必要视图、可读性与一致性。版式通过即可继续，不为轻微无关美观差异无限重采样。缺关键视图、脸不可读或身份错误时，只修复当前问题并检查新版本。

多视图拼图可能被视频模型误认成多人；按真实工具准备兼容单角色脸部/服装参考，必要时用受支持裁切工具生成并检查。不能把多人物拼图直接当剧情首帧，不能编造裁切文件或资产ID。白底/无字约束只作用于身份图，不约束片中真实场景及必要文字。

## 场景与重要道具

场景参考保存布局、门窗方向、出入口、文化/时代、时段、光源、轴线及重要物体位置，按影片比例设计。不同时间或显著环境状态建关联变体。

从全剧本和镜头表自动找到：近景/特写物件、反复出现的物件、影响动作/剧情的工具与证据、重要背景装饰及空间锚点。仅在制作需要时创建独立参考图，不把每一粒尘埃都变成资产。

重要物件推荐16:9清晰参考，体现尺寸、材料、颜色、标志结构、正侧背/关键细节及所需状态，排布按物件实际需要。真实文字、刻度与标志须可控，不能靠模型随机补字。记录每次出现的物件版本、状态、视角、场景位置与比例，通过真实参考端口附到相关镜头；名字本身不是引用。

统一展示所有必需角色、场景与道具的真实图像后，合并收集适用视觉审核；文本方案不可当成生成图。只有部分图完成时不能称完整资产阶段通过。

## 声音设计与三种音频

给每个有台词角色及旁白设声音条目：语言/口音、音高、音色、年龄呈现、速度和表演范围。已有明确偏好直接用；需要选择时提供2–3个完整且不同的方向。使用原创合成声音或已获准录音，照片/姓名/家族相似不意味着可克隆真人声音。

- **试听母带**：默认20–30秒、约24秒干声试听，含中性与情绪短句，自然速度，无背景乐。工具单次不支持时，可用同一声音组合兼容片段再核听。用户已认可声音且无需试听时可跳过。该时长不是每种视频模型的引用时长要求。
- **身份引用片段**：从批准试听中抽取干净、有讲话的短段，常见2.5–6秒只是候选；最终取决于当前接口单个/总时长与数量上限。不要把多个完整试听同时塞进视频请求。
- **实际镜头台词**：用锁定声音合成准确剧本行，保存逐字文本、实际音频和测得时长。这才是影片中的话，不能用试听测试句代替。

静默角色不创建空音频；旁白可无人物图。图像关联是制作记录，不等于TTS必需图像输入。每行保存台词ID、说话人、声音版本、音频引用、时长、放置时间与口型要求，不能靠数组顺序猜归属。具体音频输入检查见[镜头制作](production.md)，声音验收见[声音与后期](audio-postproduction.md)。
