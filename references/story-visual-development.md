# 故事与视觉开发

## 需求与第一份成果

提取用户已提供的媒介、受众、目的、语言、实拍/动画偏好、时长或范围、比例、地点文化、必需文案、素材与排除项。区分明确要求、合理推定和待决定信息；不要把示例城市、人物、时长带入新项目。

若已给定剧本，从现有版本反推场景、目标、结构及缺口，只改实际问题。若只有一句创意，先完成可拍事件、主要主体与转折的最小草案；有足够信息时直接写完整剧本和分镜。缺少可选细节不妨碍草稿。连续两次澄清仍未产出有用成果时，先给带假设的可逆版本。

用户指定40秒时，开头、对白、动作停顿、片尾和CTA都计入40秒；试听不计入片长。不把长片页数或固定10–15镜强塞给短片。台词过长先缩小事件范围或提出文本修改，不能后期强行加速或吞字。

## 可追溯视觉研究

用户要求联网研究且工具可用时，围绕真实 brief 检索并打开候选图像/视频，记录来源、看到的内容、时间段、可借鉴的构图/光线/运动、使用性质和授权状态。可以优先匹配用户指定网站或素材库；Pinterest、飞书素材、社交视频只是可选来源，不是必需账号或硬依赖。

从实际看过的参考形成情绪板，提炼5–10个有依据的关键词。区分“公开文字描述”与“实际看图/看片所得”。访问受限、没有热度/评分信息时说明限制，不编造高赞、四星评价、播放量或已研究的结论。没有搜索时可以使用本地风格库或原创方向，但标注来源类型。

参考视觉方向和59种已有风格是两条路线：选择一种连贯视觉语法，记录来源，不把研究方向冒称已有 slug。不把水墨、像素、实拍和透明玻璃等不兼容媒介机械叠加。真实证据类影片不能生成一份“档案画面”并宣称来自历史现场。

## 故事开发工作表

内部形成简明结论，无需展示隐藏推理或所有废案：

1. 把想法变成具体可见事件，解释为何适合该受众与用途；地点要参与动作、线索、阻碍或情绪，而非地标罗列。
2. 找到主体、即时目标、阻力、代价和时限。阻力可以是环境或自身，不强制善恶对抗。
3. 写明前提、主题与因果：何种行动改变何种状态，为什么结尾成立。主题词不能代替事件。
4. 从结尾的动作和结果反推铺垫；不能用巧合、突然外援或未经铺垫的性格转变解决冲突。
5. 写一句梗概：谁因何事必须做什么，遇到什么阻碍，冒着何种风险。它不同于宣传口号。

## 结构、人物与场景

短片优先组织“建立 → 推进 → 转折 → 落点”，但观察、抒情和非叙事影片可采用时间、空间、重复变化或信息递进的真实组织原则，不必硬造反派、高潮和道德顿悟。

人物设计围绕目标与行动，必要的外貌、社会处境和性格都服务当前故事。检验目标 → 策略 → 对方/环境反应 → 下一策略；删去无信息变化的重复。多人角色的台词即使遮住姓名也应有区别，非必要角色可在首次批准前合并，已批准角色不能擅自消失。

每个场景记录编号、内外景、地点日夜、目的、阻碍、可见动作、信息/价值变化与进出状态。尽量晚进入、早离开，不为每场补齐到达和寒暄。通过目光、姿态、物件接触与环境关系传达体验；不是“更舒适、更高效”等抽象说明。

对白必须有意图，回应前句或动作，符合人物词汇与节奏。避免角色互相解释都知道的事实、作者讲课、重复画面及同一策略换词。保留用户要求的精确活动信息、标题和CTA。内心愿望不自动成为旁白；第一人称参考也不自动要求主观镜头。

## 完整剧本与诊断

剧本应含标题、梗概、视觉方向、预计时长、人物/场景、所有场次、现在时可表演动作、全部对白/画外音/旁白、重要声音及完整结尾。注明声音归属，镜头参数留给分镜，不用分镜表替代剧本。

按结构、人物、场景、对白、格式/时长检查：推进有因果，结尾有铺垫，角色行为有动机，空间和物件可执行，必需文字完整，自然读演与停顿适合时长。保存并展示完整当前版本后，再进行适用的剧本审核。

## 从剧本到镜头

将每场拆为稳定镜头 ID、动作、景别、建议焦距与理由、起止估时、声音和资产需求，形成完整初步分镜。没有实际音频时标估算，不能冒充最终实测表。场景/角色/道具设计与镜头板完成后，再用实际对白长度、动作和工具约束修订。

镜头板描绘动作开始状态，而非提前完成的结果。改变景别、机位、轴线、布光或场景时需要相应的新板，不把同一张角色白底图当成所有镜头首帧。

真实图像生成后检查脸、手、服装、道具位置、光线、空间和文字；仅修复具体缺陷。已经正确的图片不为“流程完整”付费再生。摄影媒介保持相应自然细节，其他媒介保留自身纹理，不一律强加皮肤毛孔与写实照明。
