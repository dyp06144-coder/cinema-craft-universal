# 声音完整性、剪辑与成片交付

## 每镜头的声音合同

“无模型背景配乐”仅表示去掉模型自动生成的背景音乐，不等于静音。依据批准剧本与动作，为每镜头确定对白、画外音、旁白、必要拟音/效果声和环境声。无人开口也可能有旁白；无对白也可能有雨声、脚步或房间底噪。只有明确有叙事理由的区间可有意无声，不要自动添加剧本外对白或无意义效果。

每个镜头保留声音地图：

- 台词ID与逐字文本、说话人、声音/音频版本、屏内/屏外/旁白、实际起止与口型要求。
- 效果/环境事件、来源、对应动作、时间、持续、音量及保留/重建方式。
- 模型配乐是否实际不存在、已隔离移除，或仍混在源音频中。
- 最终配乐作为后期独立轨，不烘焙进准备镜头，不冒充角色声音引用。
- 有意静默区间和原因；缺少分析造成的空计划不是有意静默。

## 输入、原声与去配乐

优先使用工具真实支持的有声生成与正确声音映射，并通过支持的控制/提示请求不生成背景音乐。不虚构“仅关BGM”开关；全局音频开关可能连人声与音效一起去掉。先保存成功放行的原始素材、元数据和引用，再处理。

1. 源片确实无配乐：直接保留正确对白、效果及环境，核听，不因流程名为清理就静音。
2. 有真实独立音乐轨：仅移除该轨，核对没有误关整片或其他轨。
3. 音乐混合在总声中：用真实可用分离工具，并检查残乐、丢失辅音/音效和分离伪影。“音频轨”和音量控制不是分轨分离器。
4. 分离不可用/损坏：全混音静音只能是中间步骤；在同一准备任务内恢复精确批准台词和必要效果/环境，并实际组成有声准备片。可见讲话需要真实口型同步能力。仅补人声但丢掉动作音也不完整。
5. 无法完成：保存受影响镜头的能力阻塞，可交付明确标记的中间素材/资料，不能交付静默说话镜头并承诺以后补好。

有声准备片必须实际一起播放图像和声音，可用真实合成文件或受支持的同步预览。一个无声视频旁边放独立MP3不是完成。若用户只要静音视觉样片，可按该范围交付并标记；不能冒称已通过完整有声镜头验收。

## 声音与口型检查

检查实际声音，而不是仅看音轨/波形/字幕。区分播放器或输出设备静音与素材本身无声。宿主不能听、不能播放、没有分析能力时说明未检，不声称听过。

验收包括：所有预期文字完整、清晰、声音属于正确角色；画外音/旁白也存在；可见讲话与口型/时间匹配，无原声和替代声双重叠加；必要效果/环境在正确时刻可听；源片无不需要的模型配乐；片段裁切和续接前缀不重播旧台词；无误静音、禁用音轨或丢尾音。

保存实际资产、合成/预览版本、检查方法与证据。改声音的旧批准失效，技术重编码不改变内容时可保留其内容批准。口型不对时不能仅把干声盖上去就称同步修复。

## 后期范围先遵守

| 用户范围 | 应做的事 |
|---|---|
| 单独镜头 | 保留独立布局及每镜头批准声音，不擅自拼片 |
| 只做字幕 | 在既有组合或独立片段上做字幕，不自动重排/拼接 |
| 拼接无字幕 | 继续组装完整影片，保留对白、旁白、效果、环境和未排除的配乐，仅不放字幕 |
| 拼接加字幕 | 完成批准组合、完整声音与字幕 |
| 明确无音乐/不剪辑 | 尊重排除项，不因自动后期新增该项 |

不做字幕和不拼接是不同选择。已有工程移除字幕时只动字幕角色轨，保留片头、必要标牌和剧情文字，并检查声音仍完整。

## 实际剪辑方法

复用当前工程，读取用户已改内容和当前时间线。先做完整故事粗剪，再处理动作/台词连续性、节奏、细切、声音和必要图文。每次剪切服务动作、反应、信息或情绪，不因有素材就全塞进去。

默认清楚的硬切，保留剧本动作覆盖、目光方向、运动和轴线。J/L切可先闻其声或保留尾声，不能截断词语或把环境音错归下一场。先检查完整对白、动作与停顿，再做手柄裁切、画面微调、声音连接和结尾落点。风格规范允许的转场按实际需要使用，不机械要求全片无转场。

将生产主表与最终编辑映射分开保存：源片、源入出点、时间线位置、速度、裁切、声音与字幕偏移。合法微调剪辑不必重生成所有镜头。缩短动作、改词或改变创作意义时重开相关审核。

## 配乐、节拍与混音

用户没有明确排除音乐时，在授权后期范围内根据故事情绪、风格、场次推进、对白密度、峰值与结尾准备合适的原创新作或已获准音乐。默认可建议纯器乐；必要的无乐段落同样有效。不新增例行音乐问卷，实际音乐在终审预览中接受修改。

可以浏览公开音乐描述与可用试听获得一般乐器、节奏和能量弧线启发；Suno Discover 等不是必需能力，公开试听也不等于授权生产素材。记录看到/听到的内容及来源，不能冒称听过不可播放曲目。只把已获准的真实音乐资产用于成片，不复制受保护旋律、录音、歌词或名人声音。

配乐应覆盖实际剪辑的情绪弧线，避免每镜头随机换曲。用真实分析或实际听取的拍点/乐句/重拍，映射音乐入点和时间线位置；先保护完整台词、动作和情绪停顿，再选合适切点。不虚构已测BPM，不能为卡点加速讲话。可调整音乐段落、允许尾音和音频淡化；无可用节拍证据时保留叙事剪辑并标注未验证卡点。

## 可编辑声音角色

在工具确实支持时保持独立画面、对白/旁白、背景音乐、字幕、效果/环境轨；保存真实媒体与提示，不放空占位轨冒充完成。保留嵌入的正确人声也可，但不能同时重复播放分离人声。混合音频抽出整条并不等于分离对白与音效。

若所需分轨能力不足，保持正确可听原声并交付真实限制；不要为让轨道“看起来分开”而损坏音轨。用户要求特定可编辑工程时实际创建/验证对应格式。最终导出可正常混音，但保存可用源轨和时间映射。

音乐不能遮住语言与关键效果，用工具支持的增益、闪避和淡入淡出检查全混音。检查削波、重复、误solo/mute、导出音频被关闭和尾音丢失；风格给定响度只是目标，须用真实测量证据才可声明达标。

## 最终预览、修改与导出

展示实际当前同步预览，写明版本、时长、比例、字幕状态与音乐/对白/效果组成。默认收集“批准并导出 / 提出修改 / 再预览”；普通聊天或宿主组件均可，遵守项目明确授权与宿主强制规则。

修改请求应定位镜头、时码或轨、问题及改法，沿用同一工程；不明确时做必要澄清。更新后检查并展示新版本，旧终审不批准新声音或字幕。保持已授予的自动技术执行范围，不每修一次再问“继续吗”。

导出前重读时间线/版本，对准当前批准；等待真实完成。检查可播放画面、全部必要声音、片长/比例、字幕状态、首尾、全镜头覆盖和可访问下载位置。文件存在或导出成功提示不是可播放证据。保存检查方法及未检项，只有满足约定交付范围才宣告完成；有工程/字幕/版权来源资料时一并交付真实文件。
