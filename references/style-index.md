# 59种风格索引

先按实际创作目的、媒介和素材选择，再读取整份所选规范；不要一次载入全部风格。不明确时推荐2–3项及理由，用户已有指定则直接沿用。每份为平台无关中文制作版，详细改编范围见[来源映射](source-map.md)。

真实新闻、档案、调查、测绘与实验素材不得用生成内容冒充；模拟须清楚标识。风格默认帧率、时长、字幕、音乐与镜头语法服从具体项目要求。
