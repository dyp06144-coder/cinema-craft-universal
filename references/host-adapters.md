# 宿主适配与能力降级

## 能力优先于产品名称

每次启动或更换宿主，读取当前已提供的工具描述及权限。把下表映射到真实能力，记录名称、可用性、输入格式、输出引用、异步状态与限制；这里的“生成图像”等是逻辑能力，不是函数名。

| 逻辑能力 | 可接受的实现 | 缺失时仍可完成 |
|---|---|---|
| 成果保存与读取 | 画布文档、本地文件、云文档、附件 | 聊天完整展示及会话版本；不声称持久保存 |
| 收集决定 | 宿主表单/卡片、普通对话、外部已获准审核系统 | 普通聊天中明确记录版本与决定 |
| 参考研究 | 搜索/浏览、用户提供的可读素材库 | 指定风格或原创方向；标记未联网研究 |
| 图像与图像检查 | 原生生图、图像 API、可用设计工具、视觉查看器 | 设计稿和提示词，不冒充图片或视觉检查 |
| 语音与音频分析 | TTS、录音、受支持的参考声音/时长分析 | 完整台词与估时、声音设计；不能锁定实测时间 |
| 视频生成与任务查询 | 已连接服务、受支持的图生/文生/续接 API | 制作请求计划；不得编造已提交任务 |
| 剪辑与音轨合成 | 原生编辑器、已获准的 FFmpeg/脚本/剪辑 API | EDL/时间线说明；不得声称存在未建工程 |
| 试听/预览/导出 | 真实播放器、可用分析、真实文件与下载设施 | 列明未检/未导出项，交付已完成部分 |

## 四种运行模式

- **前期模式**：只有语言与阅读能力时，完成需求、风格、剧本、完整分镜、资产/声音说明和提示词。可以在聊天输出，不要求创建文件，不标记真实媒体已就绪。
- **资料包模式**：能读写文件时，建立项目记录、脚本、CSV/JSON 分镜和执行清单。可以可靠交给其他制作工具/人工，但不是已生成影片。
- **部分制作模式**：仅有部分图像/音频/视频能力时，完成可做且已获准的实际资产，记录缺口。没有视频模型也可使用用户素材或获准的程序化动画路线。
- **完整制作模式**：实际具备所需素材、生成/拍摄来源、剪辑、声音、预览和导出能力时，推进到可验证成片。先前模式不应因完整模式缺失而停摆。

同一项目可混合画布和本地文件。选择一个权威项目记录，映射真实路径/节点，不让两边独立覆盖当前版本。搬移成果位置不改变内容时保留既有批准；重新生成或改变内容才更新版本。

## 画布适配

可用时继续使用实际画布节点、资产端口、任务状态、原生审核卡和编辑器。先创建并读回成果，再发起审核。工具节点创建、生成任务接受、媒体就绪是不同事件。同步出错先对账，不把空节点当素材。

缺少某张卡片时，使用宿主确实提供的交互方式；普通聊天中“我批准剧本v2”可在无强制专属审批要求的宿主作为有效决定。若宿主自己强制原生审批，遵守宿主，不伪造审批。

## 文件与命令行适配

在用户项目的获准可写目录记录成果。使用已安装或已授权的工具，不因为本技能提到某工具就擅自安装。FFmpeg 可用于真实测时、合成、转码、字幕与导出；它本身不是视频生成模型，不提供人物身份或口型生成能力。

路径/命令根据实际系统构造，避免覆盖原始素材。已有剪辑工程先读取版本和用户手工修改。若后端只支持扁平混音，保留源音轨、时间线及素材对应关系；如需特定软件可编辑工程，须实际创建并验证，不能把 JSON 记录称为该软件工程。

## API 与任意 Agent

获取当前服务 schema、授权与真实可用模型；服务商名称、模型展示名与 API 模型 ID 分开保存。凭据只通过宿主安全机制取得，不写入技能、提示词、日志或项目清单。默认采用现有获准工具，不强制 Seedance、GPT Image 或特定版本。

对长任务读取真实任务 ID 和状态。宿主提供回调或调度时使用；没有时只能在本次执行中轮询，或保存状态等待下一次显式恢复，不承诺离线继续。

## 语言模型与工具能力分开

Codex、Claude、豆包或其他模型能理解相同制作规则，不代表其每个产品界面都能导入目录、读本地文件或调用媒体 API。接入方式按宿主文档配置；只支持提示词的平台使用轻量入口并按需提供参考文件。不要把整个风格库塞入单条系统提示，避免上下文截断与错误混用。
